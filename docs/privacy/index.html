PIPE UPLOAD DARKVIDEOS

Política de Privacidade

Última atualização: 10 de novembro de 2026.

1. Quem opera o aplicativo

O PIPE UPLOAD DARKVIDEOS é operado por PIPE UPLOAD DARKVIDEOS. Para dúvidas ou solicitações relacionadas a esta política, escreva para lucasjose.f@hotmail.com.

2. Como o aplicativo funciona

O aplicativo é executado no computador do usuário; não mantemos um servidor próprio para receber os vídeos ou operar as contas TikTok. A autorização ocorre por meio do TikTok Login Kit, e o envio de vídeos usa a Content Posting API, com a permissão video.upload. O vídeo enviado fica na Inbox do TikTok para revisão e conclusão pelo usuário.

3. Dados tratados

  • Autorização: tokens OAuth de acesso e atualização, e informações técnicas devolvidas pelo TikTok no processo de autorização.
  • Vídeos e metadados: os arquivos de vídeo que você escolhe enviar e os títulos, descrições ou hashtags usados como sugestão.
  • Dados locais de configuração: credenciais de integração fornecidas pelo operador e pelo usuário, mantidas na configuração local do aplicativo.

O operador não recebe cópias desses dados por meio de um servidor próprio. O aplicativo é executado no computador do usuário.

4. Armazenamento e compartilhamento

Por padrão, os tokens OAuth são gravados no arquivo local dados/tiktok_oauth.json no computador em que o aplicativo é executado. Vídeos e arquivos de trabalho também permanecem localmente até que você os envie ou os remova. O usuário é responsável por proteger o dispositivo, as cópias de segurança e as credenciais locais.

Quando você autoriza ou envia conteúdo, os dados necessários são transmitidos diretamente aos serviços do TikTok. O TikTok trata esses dados segundo a Política de Privacidade do TikTok. A hospedagem destas páginas é fornecida pelo GitHub Pages e pode processar dados técnicos de acesso conforme as práticas de privacidade do GitHub.

O pipeline possui funções opcionais que podem enviar solicitações a provedores de terceiros configurados pelo usuário, por exemplo, para geração ou processamento de texto. Essas funções são distintas do envio de vídeos ao TikTok; revise as configurações e políticas dos serviços que você habilitar.

5. Finalidades e retenção

Os tokens são usados para autorizar os envios solicitados e podem ser atualizados conforme necessário para manter a autorização. Eles permanecem no dispositivo até serem removidos pelo usuário. O TikTok controla a retenção dos vídeos e dados recebidos em seus próprios serviços, inclusive na Inbox.

6. Exclusão e revogação

Para interromper o acesso, revogue a autorização do aplicativo nas configurações da conta TikTok. Para excluir os tokens deste computador, remova o arquivo dados/tiktok_oauth.json e quaisquer credenciais TikTok que tenha colocado no arquivo local .env. Para remover um vídeo enviado à Inbox ou publicado, use os controles disponíveis no aplicativo TikTok. A remoção no TikTok é regida pelos procedimentos da própria plataforma.

Você também pode solicitar ajuda para entender ou corrigir esta política pelo e-mail lucasjose.f@hotmail.com.

7. Crianças e alterações

O aplicativo não é direcionado a crianças. Não coletamos intencionalmente dados pessoais de crianças por meio de um servidor próprio. Esta política pode ser atualizada quando o aplicativo, as integrações ou as obrigações legais mudarem; a data no início da página indica a revisão mais recente.
